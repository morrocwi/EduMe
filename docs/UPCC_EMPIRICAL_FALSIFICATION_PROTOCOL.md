# UPCC Empirical Falsification Protocol
## Brutal Ablation Programme for the Human-Potential Architecture

**Version:** 0.2  
**Status:** Empirical protocol / adversarial validation plan  
**Anchor:** `UPCC_PROTOCOL_v0.4_ANCHORED_ELEVATED.md`  
**Primary theoretical source:** *How Can AI Expand Human Potential? From Reachable Possibilities to Enduring Human Capability*, v6.17-EN  
**Mathematical source discipline:** Toledo / `TG-RFG-01`  
**Purpose:** attempt to falsify, reduce, merge, or condition the UPCC architecture before claiming that its nodes are load-bearing.

# 0. Principle of the Test Programme

This programme is not designed to prove that UPCC is correct.

It is designed to make UPCC lose.

Every node must survive a test in which:

1. the node is removed, weakened, replaced, or made sham;
2. competing explanations are made plausible;
3. artifact quality is separated from Human Return;
4. decisive assistance is reduced;
5. the problem changes;
6. assessment is performed through evidence not generated solely by the intervention itself;
7. burden, harm, and opportunity cost are recorded;
8. null, negative, and context-specific results are allowed to reduce the architecture.

The theoretical paper itself requires this standard: if trajectory traces add nothing beyond existing explanations, the framework should be reduced or abandoned.

No new Toledo equation is introduced in this empirical protocol.

Standard experimental and statistical methods are used as research methods, not as new objects in the Human–AI Readout architecture.

# 1. Core Falsification Target

The central claim under test is not:

```text
UPCC produces better-looking work.
```

It is:

```text
UPCC changes what remains with the human
after decisive assistance is reduced,
and that change survives a changed problem
and contact with constraints outside the dialogue.
```

The paper specifies an earlier mechanism that must also be tested directly. A lived event does not enter AI as a neutral object. It passes through experience, premise structure, framing, and words. Some words function as problem junctions: they connect the same originating facts to different bodies of knowledge and practice.

The empirical chain therefore begins earlier:

```text
ORIGINATING EVENT / LIVED PROBLEM
        ↓
CURRENT PREMISE STRUCTURE
        ↓
CURRENT TERM / FRAMING
        ↓
ALTERNATIVE TERM OR ADDITIONAL LENS
        ↓
CHANGED QUESTIONS
        ↓
CHANGED DOMAIN ROUTES
        ↓
CHANGED TOOLS / WORKFLOWS / CRITERIA
        ↓
NEWLY VISIBLE SKILL GAP
        ↓
PRACTICE
        ↓
WORLD RESISTANCE / FEEDBACK
        ↓
REVISED PREMISE STRUCTURE
        ↓
CHANGED HUMAN RETURN / STARTING POTENTIAL
```

The originating event can remain unchanged while the reachable route set changes.

But three levels must not collapse:

```text
different wording
≠
different route
≠
changed human potential
```

A term matters for human-potential development only if the route it opens can survive fit checking and outer-loop contact and returns something durable to the learner.

The primary evaluation point is therefore:

```text
Human Return
→ Novel Transfer
→ World Feedback
→ Net Advancement
→ Opportunity Conversion
```

not artifact quality.

The programme preserves the Toledo non-collapses:

```text
Assisted Performance ≠ Unaided Human Return
Exposure ≠ Retention ≠ Improvement
K_like ≠ K_validated
Possible ≠ Feasible ≠ Live ≠ Chosen ≠ Enacted ≠ Observed
Credential ≠ Capability
Capability ≠ Realized Opportunity
```

# 2. Outcomes: No Universal Composite Score

No total "UPCC score" is permitted.

Each experiment pre-registers the smallest set of outcomes required by the node being tested.

The common outcome families are:

```text
A. Problem Framing
   - distinction of observation vs assumption
   - constraints
   - actors / power / rights where relevant
   - risk
   - success criteria
   - justified revision of framing

B. Route Access
   - time / cost to first usable route
   - valid non-redundant routes
   - correct domain / tool / workflow linkage
   - critical omissions
   - wrong-domain routing

C. Epistemic Regulation
   - candidate-status accuracy
   - provenance tracking
   - falsifier identification
   - verification-route choice
   - calibration / error correction
   - resistance to recursive confirmation

D. Executable Capability
   - successful execution under declared constraints
   - process control
   - error detection
   - recovery after error

E. Human Return
   - what can be reconstructed
   - chosen
   - checked
   - performed
   - corrected
   - referred appropriately
   under reduced decisive assistance

F. Retention
   - delayed Human Return at pre-registered domain-appropriate delays

G. Transfer
   - performance on changed cases
   - adaptation rather than copying
   - recognition of scope failure

H. Ownership / Attribution
   - what was HUMAN, AI, or JOINT
   - human role metadata where relevant
   - decisive assistance still required

I. Burden / Loss
   - time
   - cognitive effort where validly measured
   - language burden
   - financial burden
   - frustration / emotional burden where validly measured
   - opportunity cost
   - harmful errors

J. Barrier Change
   - barrier removed
   - barrier reduced
   - barrier unchanged
   - wrong barrier diagnosis

K. Opportunity Change
   - newly reachable action
   - successful referral
   - access to practice
   - permission / credential / network change where relevant

L. Provenance and Warrant
   - evidence source
   - assessment independence
   - claim strength
   - uncertainty
```

These map naturally into the Toledo Human Return and Net Advancement objects.

# 3. Semantic-to-Capability Cascade

This is a direct empirical reading of the paper's problem → word → route → practice → revised-premise mechanism.

## Level 0 — Hold the originating facts constant

For a term-change experiment, the underlying case must remain fixed.

Researchers freeze:

```text
events
timeline
material constraints
actors
rights
power relations
risks
resources
institutional conditions
```

The manipulated variable is the term, framing, or additional lens—not the facts.

This is essential because the paper claims that the event can remain unchanged while the questions and reachable tools change.

---

## Level 1 — Wording change

Measure whether the manipulation merely changes language.

Possible observations:

```text
different nouns
different metaphors
different explanation style
different rhetorical tone
```

This level alone provides no evidence of potential development.

---

## Level 2 — Question-set change

Measure whether the term changes what questions become askable or salient.

Examples:

```text
enemy
→ threat / vulnerability / protection questions

counterparty
→ interests / positions / negotiation sequence questions

stakeholder
→ affected parties / power / participation questions

potential partner
→ coalition / coordination / complementarity questions
```

The key outcome is not lexical novelty but systematic change in problem-relevant inquiry.

---

## Level 3 — Route-set change

Measure whether the changed questions expose different:

```text
domains
tools
workflows
evidential standards
checking criteria
practitioners
skill requirements
```

This is the direct target of the paper's P2.

---

## Level 4 — Additive-lens preservation

The paper explicitly requires:

```text
add a lens
not
replace inconvenient reality
```

Therefore every route receives two separate judgments:

```text
ROUTE OPENING:
What new structure did the term reveal?

FACT PRESERVATION:
What material facts, rights, power relations, risks, or constraints remained represented?
```

A route is not successful merely because it is novel.

A route that opens new tools while deleting a decisive fact is a routing failure.

---

## Level 5 — Skill-gap visibility

Measure whether the route reveals something the learner now recognizes they cannot yet do.

Examples:

```text
"I need to know how to calculate this."
"I need to learn this workflow."
"I need a practitioner."
"I need permission."
"I should not do this myself."
```

This is a crucial transition from vocabulary to learning obligation.

---

## Level 6 — Practice and world contact

The learner follows selected routes far enough to encounter:

```text
practice difficulty
tool constraints
evidence
expert criticism
simulation
institutional rules
real or safely represented consequences
```

A route that looks useful in dialogue but cannot survive these conditions should be revised or rejected.

---

## Level 7 — Premise revision

Do not infer a hidden psychological essence.

Record observable premise-structure traces before and after:

```text
what the learner treats as observation
what the learner treats as assumption
what counts as a constraint
what counts as evidence
criteria of success
known tools
known checking routes
boundary / referral judgment
questions the learner now asks
```

The important test is whether world resistance causes justified revision.

---

## Level 8 — Changed starting potential

Only now ask whether the learner begins a later problem differently:

```text
sees distinctions sooner
finds usable terms at lower cost
knows more routes
selects better checks
recognizes skill gaps
acts more competently
recognizes limits
transfers retained knowledge
```

This is the downstream human-potential outcome.


# 4. Measurement Must Be Valid Before Nodes Are Tested

Before an ablation experiment can be interpreted, the measurement system itself must survive validation.

Every learner-level claim uses:

```text
CLAIM
    what capability is being claimed?

TASK
    what situation elicited performance?

OBSERVATION
    what was actually observed?

WARRANT
    why does this observation support this claim in this context?
```

For every primary outcome:

```text
- construct definition is frozen before analysis;
- tasks are reviewed for construct underrepresentation;
- tasks are reviewed for construct-irrelevant variance;
- at least some tasks are independently authored;
- artifact scoring and Human Return scoring use separate raters;
- high-stakes claims are not evaluated only by the intervention designer;
- raters are blind to experimental condition where feasible;
- inter-rater agreement / generalizability is estimated;
- task and rater variance are reported;
- cross-language or cross-cultural comparisons require evidence that the readout functions comparably;
- measurement failure blocks causal interpretation.
```

A statistically significant treatment difference on an invalid readout does not validate UPCC.

# 5. Adversarial Task Bank

The test bank should contain normal tasks and deliberately hostile tasks.

Required hostile families include:

```text
1. Seductive wrong-domain route
   Every component fact is true, but the connection to the problem is wrong.

2. Context deletion
   A reframing makes rights, power, law, physical constraint, or risk disappear.

3. False-consensus trap
   Several AI answers inherit the same false premise and agree fluently.

4. Mechanical-success trap
   The procedure can be executed correctly without understanding when it applies.

5. Structural-barrier trap
   Apparent skill failure is actually permission, credential, tool, time, network, or opportunity failure.

6. Expert-language trap
   The learner can use domain vocabulary but cannot perform the domain task.

7. Artifact-quality trap
   AI can produce an excellent artifact while carrying decisive reasoning.

8. Transfer trap
   Surface features change while the underlying principle remains.

9. Boundary trap
   The correct answer is "stop / refer / obtain authority."

10. Local-fit trap
    Globally plausible advice conflicts with the actual local rule, institution, language, or resource condition.

11. Group-attribution trap
    A team produces a correct answer while one individual cannot reproduce the decisive reasoning.

12. Sequencing trap
    Textbook order conflicts with a route-specific prerequisite or safety dependency.

13. Recursive-confirmation trap
    AI becomes more coherent without any new evidence entering.

14. World-resistance trap
    An AI-generated plan looks correct but fails against an external simulator, dataset, practitioner judgment, or real constraint.
```

The hidden trap is not disclosed to participants.

Independent domain experts establish the task ground truth, acceptable uncertainty, and valid referral boundary before randomization.

# 6. Five Experimental Layers

## Layer A — Software / Compiler Red Team

Before human efficacy testing, run UPCC against adversarial cases.

Goal:

```text
Does the compiler itself preserve the architecture?
```

Test:

```text
Barrier classification
Route generation
Cross-domain fit
Candidate status
Verification escalation
Attribution
Governance
Dependency records
Referral
Opportunity claims
```

A software failure is not rescued by later human performance.

---

## Layer B — Isolated Mechanism Experiments

Test the paper's P1–P10 and individual nodes separately.

Use tightly controlled tasks to maximize causal interpretability.

---

## Layer C — Component Ablation / Optimization

Use factorial or fractional-factorial designs for components that can safely be toggled independently.

Candidate factors include:

```text
Barrier Readout
Human Endorsement
Visible Candidate Status
Independent Verification
Adaptive Scaffold
Practice
Withdrawal
World Feedback
```

Not all factors belong in one experiment.

Factors that are structurally sequential or ethically inseparable must not be forced into an inappropriate factorial design.

---

## Layer D — Adaptive-Policy Experiments

Use sequential randomization for decisions that occur repeatedly over time.

Examples:

```text
whether to scaffold after a failed attempt
which safe scaffold to give
whether to fade support after a successful reattempt
whether to intensify verification when uncertainty remains
whether to reroute after a barrier persists
```

A SMART design is appropriate for comparing multistage adaptive decision rules.

A micro-randomized design is appropriate when a low-risk intervention decision recurs many times within learners.

---

## Layer E — Confirmatory and Generalization Trials

Only after component optimization:

```text
Full optimized UPCC
vs
strong active comparator
```

The comparator must have:

```text
equal learning time where possible
equal access to AI
comparable content
comparable instructor contact
comparable practice time
```

A weak "no AI" control is insufficient as the sole comparator.

Replication must then test:

```text
different domains
different task structures
different languages
different institutions
different resource conditions
different age/governance settings
```

"Universal" is not accepted from one site or one discipline.

# 8. Proposition-Specific Kill Tests

## P1 — Problem Ownership

Use a three-condition design:

```text
A. meaningful agency:
   learner helps define aims, constraints, and success criteria

B. yoked framing:
   receives the exact finalized task produced by a matched learner

C. fully pre-shaped:
   standard task with predefined criteria
```

The yoked condition is essential because it controls for the possibility that the learner-owned condition simply produced a better task.

Primary outcomes are behavioral trajectory traces, not satisfaction questionnaires.

A strong failure occurs if A does not improve framing revision, sustained problem engagement, or later transfer relative to B after task quality is held constant.

---

## P2 — Working Words / Route Set

P2 must be tested as a nested cascade rather than a text-divergence experiment.

Hold the originating event and material facts constant.

Randomize, within or between learners as appropriate:

```text
A. current / ordinary term

B. neutral paraphrase
   changes wording without intentionally opening a new practice system

C. domain-opening additive term
   intended to expose a plausible additional practice system

D. seductive misrouting term
   real terminology that makes one important constraint disappear
```

Freeze AI model, system instructions, available context, and task facts.

### Stage 1 — Question divergence

Score whether the term systematically changes the questions raised.

### Stage 2 — Route divergence

Independent experts code:

```text
domains surfaced
tools surfaced
workflows surfaced
checking criteria surfaced
skill requirements surfaced
practitioner / referral routes surfaced
```

### Stage 3 — Fact preservation

Code whether the route preserves:

```text
rights
power
risk
physical constraints
institutional constraints
resource constraints
other facts declared material to the case
```

### Stage 4 — Reachability

Ask whether the learner can identify which routes are:

```text
merely interesting
feasible
live for this person
requiring learning
requiring referral
```

### Stage 5 — Downstream consequence

Select a subset of routes and carry them through:

```text
verification
practice
safe world contact
Human Return
```

Measure whether term-induced route differences produce differences in:

```text
tool selection
skill-gap recognition
practice behaviour
decision quality
premise revision
later transfer
```

The key falsification distinctions are:

```text
If term changes only prose:
    P2 mechanism is weak at that task.

If term changes routes but routes do not survive fit checking:
    route opening occurred, but potential did not develop.

If term changes valid routes and later Human Return:
    evidence supports the full semantic-to-capability mechanism.
```

The experiment must therefore report **semantic divergence**, **route divergence**, and **capability consequence** separately.

---

## P3 — Orientation Faster Than Expertise

Separate two tests deliberately.

### Orientation test

Measure:

```text
time / effort to identify:
    useful vocabulary
    credible sources
    workflow structure
    relevant practitioner
    valid next question
```

### Expertise test

Measure:

```text
conversation with blinded practitioner
tool execution
performance under domain constraints
error detection
```

The prediction is a divergence: orientation can become cheaper faster than genuine performance.

If vocabulary and orientation improve but practitioner-level execution does not, that supports the distinction rather than constituting failure.

---

## P4 — Good Routing Preserves Important Facts

P4 is the adversarial counterpart to P2.

The paper does not claim that the "best" word replaces the old framing.

It requires additive lenses where multiple realities remain simultaneously true.

Construct cases where:

```text
the originating facts are fixed;

Lens A reveals a genuine practice system;

Lens B reveals a second genuine practice system;

a replacement framing would incorrectly erase a material fact.
```

Example structure:

```text
LABOUR lens:
    rights
    duties
    authority
    employment rules

SERVICE / CAPABILITY lens:
    value delivered
    scope
    workflow
    professional development
    skill bottleneck
```

The correct architecture permits both to remain live.

Randomize conditions such as:

```text
A. original lens only

B. additional lens while explicitly preserving original facts

C. replacement lens that suppresses original constraints

D. multi-lens condition with explicit fit checking
```

Primary outcomes:

```text
new valid routes discovered
critical-fact preservation
wrong-domain routing
unsafe or unlawful recommendations
skill-gap visibility
decision quality
later premise revision
```

A strong success is not maximum route diversity.

It is:

```text
more useful reachable structure
without deletion of facts that remain materially true.
```

A hard failure occurs if the additive-lens gate does not reduce context deletion or wrong-domain action compared with replacement reframing.

---

## P5 — Artifact Quality Is Not Human Potential

This must be tested with artifact quality deliberately decoupled from human reasoning.

Example:

```text
Arm A:
AI coaches reasoning but learner performs decisive steps.

Arm B:
AI performs decisive reasoning.

Before artifact scoring:
both receive the same final editorial polishing process.
```

Independent raters score artifacts without condition information.

Different raters later score Human Return with decisive AI removed.

The core non-collapse is empirically valuable only if similarly polished artifacts can coexist with meaningfully different Human Return.

---

## P6 — Reflective Dissonance

Insert the same contradiction into all conditions.

Manipulate only the learner's required response to it.

```text
A. contradiction visible, no regulation instruction

B. contradiction + "identify what does not fit"

C. contradiction + classify mismatch + specify what evidence would discriminate

D. C + access to genuinely independent check
```

The critical transition is not noticing.

It is moving from mismatch to evidence-seeking and warranted revision.

---

## P7 — Independent Verification Versus More Answers

This should be one of the harshest experiments.

Build cases with a seeded false premise likely to propagate through AI answers.

Randomize:

```text
A. one AI answer

B. multiple AI answers / models sharing the same framing

C. one genuinely independent source, method, dataset, or evaluator

D. multiple AI answers + one independent route
```

Measure:

```text
error correction
confidence calibration
candidate downgrade
decision quality
```

If B repeatedly performs as well as or better than C under well-constructed tasks, the architecture's claim about evidential independence requires major revision.

---

## P8 — Developed Potential Must Survive Assistance

This is the central kill test.

Use an optimization experiment in which the outer-loop components are manipulated where ethically permissible:

```text
Independent Verification
Practice
External / World Feedback
Withdrawal of Decisive Assistance
```

Immediate artifact quality is secondary.

Primary evidence is collected later with:

```text
reduced assistance
changed surface features
new problem
new error
new decision point
```

If the full outer-loop package improves only assisted performance but does not improve retention, error detection, process control, or transfer, the central human-potential mechanism is seriously weakened.

---

## P9 — Lower the Cost of Validation, Practice, and Referral

This requires institutional rather than only individual manipulation.

Possible ethical design:

```text
usual educational infrastructure
vs
enhanced low-cost verification / practice / referral access
```

Prefer cluster randomization or phased/waitlist implementation when individual contamination is likely.

Measure:

```text
time and cost to check
completion of checking
access to practice
appropriate expert referral
retained capability
conversion from visible route to actionable route
```

The important outcome is not satisfaction with the service.

It is whether possibilities become responsibly reachable.

---

## P10 — Entrusted Participation

Do not begin with a self-report trust scale.

Use two stages.

### Stage 1 — controlled assessor experiment

Give external assessors competence-matched portfolios that vary verified histories of:

```text
disclosing uncertainty
choosing proportionate checking
correcting errors
working within scope
responsible referral
```

Measure what level and kind of consequential work they would entrust and why.

### Stage 2 — longitudinal field validation

Track whether real histories of correction predict later entrusted work and whether that entrustment is followed by responsible performance.

P10 should remain a developmental hypothesis unless both stages converge.

---

# 9. Adaptive Scaffold Test: Use Repeated Randomization

The scaffold node is inherently adaptive.

A one-time A/B test is insufficient.

At eligible low-risk decision points after an attempt, randomize among safe alternatives such as:

```text
no additional support
hint
worked example
procedural information
prompt to explain
feedback
```

Then observe the proximal next attempt and later Human Return.

This allows testing:

```text
what support
for whom
at which state
after what error
produces what immediate effect
and what later dependence
```

A scaffold that improves the next click but worsens later Human Return is not automatically beneficial.

---

# 10. SMART Test for the Adaptive River

After component screening, use a Sequential Multiple Assignment Randomized Trial to test adaptive decision rules.

Example decision structure:

```text
Stage 1:
candidate minimal scaffold
vs
alternative safe scaffold

↓ observe response

If adequate response:
    maintain
    vs
    fade decisive support

If inadequate response:
    intensify support
    vs
    reroute / re-diagnose barrier

↓ observe Human Return

If verification uncertainty remains:
    independent check
    vs
    additional low-risk practice first
```

The scientific target is not "which treatment wins?"

It is:

```text
which decision rule
given which readout
produces better later Human Return
with acceptable burden and safety?
```

SMART development must be followed by a separate confirmatory trial of the resulting adaptive policy.

---

# 11. Factorial Optimization Rules

Factorial experiments are useful only for components that are:

```text
ethically toggleable
operationally separable
implemented with fidelity
not logically required by another manipulated component
```

Candidate components for a first optimization trial might include:

```text
Visible Candidate Status
Independent Verification Prompt
Structured Practice
Withdrawal Test
External Feedback
```

Barrier Readout and Human Endorsement may require separate experiments because they influence which later intervention is even appropriate.

Do not interpret a non-significant main effect as proof of irrelevance when a pre-specified interaction is theoretically central.

Do not perform unrestricted interaction fishing.

---

# 12. Strong Controls

UPCC must beat serious alternatives.

Minimum comparator set across the research programme:

```text
Control 1:
ordinary GenAI dialogue

Control 2:
strong AI tutor using explanation, hints, feedback, and practice
but without the full Human-Return / verification architecture

Control 3:
non-AI high-quality instruction where appropriate

Control 4:
optimized UPCC
```

Equalize, where feasible:

```text
time
content exposure
AI model access
token budget
practice quantity
teacher contact
```

If UPCC wins only because participants spent twice as long or received more expert contact, the architecture has not been isolated.

---

# 13. Delayed Return and Transfer Battery

Immediate post-test is not enough.

Each domain pre-registers at least:

```text
an immediate return
a delayed return
a later delayed return where feasible
```

The exact intervals are domain-appropriate and fixed before confirmatory analysis.

Each return battery includes some combination of:

```text
reconstruct
select
verify
execute
detect error
repair
transfer
refer
generate next question
```

AI can remain available in some transfer conditions.

The decisive manipulation is whether the human still owns the target capability, not whether all tools disappear.

---

# 14. Assistance-Fading Shock Tests

To distinguish coupled performance from Human Return, use pre-registered perturbations such as:

```text
remove conversation history
change AI model
withhold AI at one decisive stage
replace full answer with tool-only access
change task surface features
insert a novel error
delay the return task
change source format
change language where appropriate
```

Do not use all perturbations in every study.

Choose those that attack the capability the study claims has become human-owned.

---

# 15. Falsification Decision Rules

Before outcome data are unblinded, define a **smallest effect size of interest (SESOI)** for each primary node test.

Power confirmatory tests for the SESOI, not for an optimistic pilot effect.

Recommended decision categories:

```text
SURVIVES
    targeted delayed Human Return / transfer improves by at least the
    pre-registered meaningful amount without unacceptable burden/harm.

CONDITIONAL
    effect exists only under identifiable learner, task, domain, or
    contextual conditions.

MERGE
    node has value but cannot be empirically separated from a neighboring node.

REMOVE
    well-powered ablation shows practical equivalence and no important
    beneficial interaction; node adds burden or complexity without return.

REVERSE
    the ablated condition performs meaningfully better.

FALSIFY PROPOSITION
    the pre-registered prediction repeatedly fails under valid measurement,
    good fidelity, strong controls, and independent replication.
```

One null study is not enough to erase a theory.

But repeated rescue by changing outcomes, subgroups, or definitions after seeing results is forbidden.

---

# 16. Statistical Discipline

Primary analysis principles:

```text
- intention-to-treat for randomized human experiments;
- multilevel models when learners, tasks, classes, or institutions are nested;
- repeated-measures structure modeled explicitly;
- factorial main effects and only pre-specified interactions;
- multiplicity control for co-primary outcomes;
- confidence intervals and effect sizes, not p-values alone;
- equivalence tests when the scientific question is "does the node add anything meaningful?";
- sensitivity analyses for attrition and missingness;
- treatment-fidelity analysis reported separately from ITT;
- causal mediation only when temporal order and identification assumptions are defensible;
- no post-hoc composite "potential score";
- no selective reporting of only the dimension that improved.
```

Use generalizability / variance-component analyses where task and rater sampling materially affect the Human Return claim.

---

# 17. Power Discipline

Do not select sample size from convention.

For each confirmatory test:

```text
1. validate the outcome sufficiently to estimate relevant variance;
2. specify the smallest effect that would justify keeping the node;
3. power the study for that effect with the actual design:
      individual
      cluster
      factorial
      repeated
      SMART
      MRT
4. include expected attrition;
5. power pre-specified interactions only when the theory genuinely depends on them.
```

A target of at least high power for the pre-registered meaningful effect is preferable to a minimally powered demonstration study.

Pilot data estimate feasibility and variance.

They do not decide the confirmatory hypothesis after the fact.

---

# 18. Blinding and Independence

Where feasible:

```text
- outcome raters blind to condition;
- artifact raters different from Human Return raters;
- analysts receive masked condition labels until the analysis script is frozen;
- independent experts establish adversarial task ground truth;
- external evaluators assess high-stakes Human Return;
- AI model/version/system prompt are logged and frozen during confirmatory trials;
- external verification sources are not generated from the same intervention dialogue;
- model-to-model agreement is not coded as independent evidence merely because model names differ.
```

---

# 19. Intervention Fidelity

Every node activation is logged.

For each participant/cycle record:

```text
was barrier readout actually performed?
was human endorsement actually obtained?
was candidate status visible?
was verification genuinely independent?
what scaffold was actually delivered?
what decisive assistance remained?
was practice executed?
what counted as world feedback?
was transfer genuinely novel?
```

If an ablated condition accidentally receives the removed node through the AI or teacher, the contrast is contaminated.

Primary analysis remains ITT, but fidelity failure must be disclosed.

---

# 20. Safety Boundary

No ablation may deliberately remove a safety floor in a high-stakes setting.

Examples:

```text
Do not randomize patients to "no verification" of medical advice.
Do not randomize legal action to "no authority check."
Do not let unqualified learners perform dangerous engineering work.
Do not remove child-safety governance.
```

Test these nodes with:

```text
synthetic cases
simulation
sandbox
retrospective records
low-risk tasks
controlled assessor experiments
```

Safety is a constraint on experimental design, not a nuisance variable.

---

# 21. Cross-Cultural and Cross-Language Generalization

Do not assume that one Human Return task means the same thing everywhere.

For multi-context claims:

```text
- perform local domain analysis;
- check translation and task interpretation;
- inspect differential task functioning where appropriate;
- test measurement invariance only when latent comparisons are intended;
- allow functionally equivalent rather than literally identical tasks;
- preserve Life-Capital Context and institutional differences;
- report context-specific effects before pooling.
```

A pooled global average that hides opposite local effects is not evidence of universality.

---

# 22. Asia Must Be a Primary Validation Region, Not an Afterthought

A global programme should not develop entirely in English-language Western university settings and later "replicate in Asia."

At minimum, the validation programme should deliberately include variation in:

```text
language
institutional authority
resource access
teacher role
family / adult oversight where relevant
credential structure
local professional regulation
AI access
availability of verification and practice
```

Thai / Southeast Asian implementation can therefore serve as a primary test of the architecture's context sensitivity, not merely a translation site.

# 24. Independent Replication Rule

The first successful study is discovery.

At least one confirmatory replication should change:

```text
research team or site
task pool
domain
learner population
or institutional context
```

before a node is treated as generally load-bearing.

Where feasible, external replication should use the same preregistered construct and falsification rule but independently authored tasks.

# 25. Architecture-Level Kill Criteria

The architecture as a whole requires major reduction if any of the following patterns survive strong replication:

```text
1. Artifact quality reliably captures Human Return, retention, and transfer,
   making the artifact/human distinction empirically unnecessary.

2. Independent verification does not outperform correlated conversational
   agreement in correcting error.

3. Verification + practice + world feedback + withdrawal do not improve
   post-assistance Human Return relative to fluent dialogue.

4. Barrier-sensitive routing does not improve decisions over ordinary
   performance-based personalization.

5. Retention and transfer are not meaningfully predicted by the trajectory
   traces the architecture records.

6. Opportunity Conversion does not add explanatory or predictive value
   beyond ordinary performance/capability measures.

7. The same effects can be explained by a substantially simpler architecture
   with fewer nodes and equal predictive / causal performance.
```

The final criterion is essential.

UPCC does not survive merely by showing that every node sounds reasonable.

It must earn its complexity.

# 30. The Hardest Single Experiment

If resources permit only one decisive test, run the P8 outer-loop dismantling study.

```text

withdrawal of decisive assistance
```

```text

```

under reduced assistance.

Do not use artifact quality as the primary outcome.

If the outer-loop components do not produce a meaningful post-assistance advantage, the heart of the paper's mechanism requires revision.

# 31. The Hardest Epistemic Experiment

Run P7 with a deliberately shared false premise.

Compare:

```text
many fluent correlated answers
vs
one genuinely independent verification route
```

If correlated agreement reliably corrects error as well as independent resistance under controlled conditions, the framework's emphasis on verification-route independence is weakened.

If independent resistance wins despite fewer answers and less prose, that directly supports one of the architecture's most distinctive claims.

# 32. The Hardest Human-Potential Test

After the entire intervention:

```text
remove or reduce decisive AI support
change the problem
change some surface conditions
introduce an unfamiliar error
allow referral
```

Then ask:

```text
Can the person still see what matters?
Can they find a route?
Can they know what is only a candidate?
Can they choose an appropriate check?
Can they perform the relevant part?
Can they detect or repair failure?
Can they recognize the boundary of their competence?
Can they reach an option that was previously not realistically reachable?
```

That is the direct empirical test of the paper's definition of developed human potential.

# 33. Scientific Outcome

The desired result of this programme is not necessarily "UPCC survives."

The valid outcomes are:

```text
UPCC survives largely intact.

UPCC survives only under specified contexts.

Some nodes merge.

Some nodes are removed.

Adaptive rules replace fixed rules.

Some paper propositions are falsified.

A simpler architecture explains the data better.

The architecture survives but its universal scope is narrowed.
```

Any of these outcomes improves the theory if the evidence is strong.

A node earns its place only when its presence changes a result the paper actually cares about.

Not:

```text

more satisfaction
more text
more confidence
more AI use
better-looking output
```

but:

```text
better problem perception
better reachable routes
better epistemic regulation
greater executable capability
retention under reduced decisive assistance
transfer
boundary judgment
responsible action
realistic opportunity conversion
```

If a node cannot move one of those outcomes beyond a simpler alternative, it should not remain in the architecture merely because it has theoretical appeal.
